{% comment %} One dialog per page for the document actions that ask something first (return: a reason; replace: a file; delete: "are you sure"). A trigger (documents/_actions.html) loads the form into #document-dialog-body with HTMX and opens it; Escape closes it and the focus goes back to the trigger. Without JavaScript the trigger is a link to the form's page. {% endcomment %}
